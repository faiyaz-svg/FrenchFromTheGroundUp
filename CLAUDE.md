# French From the Ground Up

A self-study French textbook for one reader: an adult in Toronto starting French from zero, practising about 30 minutes a day. The goal is CEFR B2 for speaking, listening and writing: conversations in Montreal and Quebec, bilingual work in Canada (federal jobs), texts and emails. Standard French first, plus understanding Quebec French. Literature is out of scope. The Markdown in `docs/` is published to https://faiyaz-svg.github.io/FrenchFromTheGroundUp/ and also read directly in VS Code. The sibling books are https://faiyaz-svg.github.io/MathFromTheGroundUp/, https://faiyaz-svg.github.io/CSFromTheGroundUp/ and https://faiyaz-svg.github.io/MusicFromTheGroundUp/.

## Rules to follow

- Writing: `STYLE.md`. Every page must follow it, including the list of AI-writing patterns to avoid and the French-book conventions. Em dashes are the most common slip.
- Lesson structure: `LESSON_TEMPLATE.md`.
- Site look: `DESIGN.md`.
- Don't make decisions the reader hasn't agreed to. Ask first when a change goes beyond what was requested.
- Every dialogue, text and exercise is written for the book. No song lyrics, TV transcripts or textbook exercises.

## Layout

- `docs/00-start-here`: nine pages (how to use the book, the 30-minute routine, setup, standard vs Quebec French, practising in Toronto, levels and goals, credits).
- `docs/01-...` to `docs/16-...`: the book in reading order, as 16 stages on four lines: A1 (stages 1 to 4, green), A2 (5 to 8, orange), B1 (9 to 12, yellow), B2 (13 to 16, blue). Each stage folder is flat (`NN-slug.md` lessons, numbering restarts in each stage) with an `index.md` overview, cheat sheet and "Listen and watch at this level". Each lesson has one area (sounds, grammar, words, listen, speak, read, write, quebec) and the last lesson of a stage has the `review` flag, all in `tools/lessons.yml`.
- Stages 1 to 8 are written in English. Stages 9 and 10 give instructions and section headings in French. Stages 11 to 16 explain in French with `.fr`/`.en` paragraph pairs and a button to switch.
- `docs/practice`: drills that run in the browser (conjugation, le or la, fill in the blank, dictation, numbers, Quebec words, Say it). Data is in `docs/assets/drills/*.json`. `docs/reference`: glossary, verb tables, IPA chart, Quebec and France words, false friends, email formulas, numbers and dates, linking words, common mistakes, Montreal phrasebook, media list.
- French examples are `fr` code blocks (one line each: `[Speaker:] French [{qc}] [{x}] [| English]`). `docs/javascripts/speak.js` adds play and mic buttons. Italics are reserved for French and are clickable. Every lesson ends with a New words table that feeds Anki.
- `mkdocs.yml` holds the site config and the `nav` (generated between `# nav:start` and `# nav:end`). `tools/lessons.yml` lists every lesson; run `tools/build_nav.py` after adding one.
- The home page is a line map (a métro map) generated by `tools/build_nav.py` between `<!-- lines:start -->` and `<!-- lines:end -->`; it also writes `docs/assets/lines.json` for the line strip on lesson pages.
- `anki/rows_from_lessons.py` reads the New words tables into `anki/cards/<stage>.tsv`, then `anki/build_decks.py` builds `docs/downloads/anki/<stage>.apkg`. Audio is Anki's `{{tts fr_CA:French}}`.
- `tools/figures/` draws the few SVG figures into `docs/assets/figures/`.
- Check tools (local only, in `.venv`): `tools/check_french.py` (LanguageTool, conjugations with verbecc, IPA, gender), `tools/check_vocab.py`, data fetched by `tools/fetch_data.py` into `tools/data/` (gitignored).

## Commands (Windows, Git Bash)

```bash
py -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/zensical serve                    # preview at http://127.0.0.1:8000/FrenchFromTheGroundUp/
.venv/Scripts/zensical build --clean
.venv/Scripts/python tools/lint.py docs/01-first-sounds-and-greetings   # style and template check
.venv/Scripts/python tools/check_french.py docs/01-first-sounds-and-greetings
.venv/Scripts/python tools/build_nav.py         # after adding lessons: nav, progress, line map, stage lists
.venv/Scripts/python tools/link_planned.py      # turn <!-- link: ... --> comments into links once targets exist
.venv/Scripts/python tools/build_reference.py   # glossary and common mistakes from the lessons
.venv/Scripts/python anki/rows_from_lessons.py  # New words tables to anki/cards
.venv/Scripts/python anki/build_decks.py
.venv/Scripts/python -m unittest anki.test_build_decks
node --test tools                               # drill grading tests
```

Use `--tracked` with `build_nav.py`, `link_planned.py`, `build_reference.py` and `rows_from_lessons.py` when committing, so only committed lessons get links.

## Before committing a page

1. Run the self-check in `STYLE.md`: `tools/lint.py` (em dashes, curly quotes, banned words and patterns, template sections, routine minutes, `.fr`/`.en` pairs, `fr` fence lines).
2. Run `tools/check_french.py` on the page. Every French line passes, or is marked `{qc}` or `{x}` on purpose.
3. Recompute every answer, conjugation and table value. Check every Quebec claim and every changing fact against its source.
4. `zensical build --clean` must report no issues.
5. A different reviewer reads each stage's French (a proofreader agent, never the writer) before it is committed.

## Git

- Work on `main`. The whole repo has a hard cap of 100 commits, so commit a few lessons at a time. Check the count with `git rev-list --count HEAD`. Short, plain messages ("add stage 1 lessons 1 to 4").
- No Co-Authored-By or any other attribution lines in commits or pull requests, even if a tool suggests one.
- No force pushes. Never amend a pushed commit.
