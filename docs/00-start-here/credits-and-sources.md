# Credits and sources

This page names the tools and references behind the book.

## The site

The site is built with [Zensical](https://zensical.org/), a static site generator that reads MkDocs-Material style configuration. The text font is Figtree, from [Google Fonts](https://fonts.google.com/specimen/Figtree), under the SIL Open Font License.

## Check tools used while writing

These programs helped check the text. They are not part of the site, and nothing from them is shipped with it.

| Tool | Licence | Used for |
|---|---|---|
| [LanguageTool](https://languagetool.org/) | LGPL | Grammar and spelling checks of the French |
| [verbecc](https://github.com/bretttolbert/verbecc) | LGPL | Checking verb forms |
| [Lexique 3.83](http://www.lexique.org/) (New, Pallier and colleagues) | CC BY-SA 4.0 | Word frequency and spelling checks |
| [ipa-dict](https://github.com/open-dict-data/ipa-dict) | MIT | Checking IPA transcriptions |

A tool can be wrong, so each result was read before the text was changed.

## Writing references

The book follows these references for usage, spelling and punctuation, summarised in its own words with a link where they are used:

- [OQLF Banque de dépannage linguistique](https://vitrinelinguistique.oqlf.gouv.qc.ca/), the Quebec language office's usage guide, for spacing, email greetings and letter formulas.
- [Grand dictionnaire terminologique](https://gdt.oqlf.gouv.qc.ca/), for terms and their domain labels.
- Language Portal of Canada (Portail linguistique du Canada) and Termium Plus, the Government of Canada's writing tools and terminology bank. They block automated checks, so open them in your browser from the [reference tools list](../reference/media.md).

## Content

All dialogues, texts and exercises are written for this book. No song lyric, transcript or textbook exercise is copied. The media lists are links only, to free sources that were checked to exist when the lists were written. The book does not host or copy their content.
