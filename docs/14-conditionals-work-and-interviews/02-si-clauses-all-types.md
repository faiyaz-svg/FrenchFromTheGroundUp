## L'idée

Une phrase avec *si* a deux parties : la **proposition de condition** (celle qui commence par *si*) et la **proposition de résultat**. Le temps du verbe dans chaque partie dépend de la réalité de la condition : possible, imaginée ou impossible parce que le moment est passé. Il y a une règle qui ne change jamais : après *si*, jamais de conditionnel et jamais de futur.
{: .fr }

A *si* sentence has two parts: the **condition clause** (the one that starts with *si*) and the **result clause**. The verb tense in each part depends on how real the condition is: possible, imagined, or impossible because the moment has passed. One rule never changes: after a *si* of condition, never the conditionnel and never the futur.
{: .en }

### Les trois types

Le type 1 parle d'une condition réelle ou probable : *si* + présent, puis le futur, le présent ou l'impératif. Le type 2 parle d'une condition imaginée ou peu probable : *si* + imparfait, puis le conditionnel présent. Le type 3 parle du passé, quand il est trop tard : *si* + plus-que-parfait, puis le conditionnel passé.
{: .fr }

Type 1 is about a real or likely condition: *si* + présent, then the futur, the présent or the imperative. Type 2 is about an imagined or unlikely condition: *si* + imparfait, then the conditionnel présent. Type 3 is about the past, when it is too late: *si* + plus-que-parfait, then the conditionnel passé.
{: .en }

| Type | Après *si* | Résultat | Exemple |
|---|---|---|---|
| 1, réel | présent | futur, présent, impératif | *Si tu viens, nous mangerons ensemble.* |
| 2, imaginé | imparfait | conditionnel présent | *Si tu venais, nous mangerions ensemble.* |
| 3, passé | plus-que-parfait | conditionnel passé | *Si tu étais venu, nous aurions mangé ensemble.* |
| Mixte | plus-que-parfait | conditionnel présent | *Si j'avais accepté, je travaillerais à Ottawa maintenant.* |

Voici trois phrases côte à côte, pour entendre la différence de sens. *Si je finis tôt, je passe te voir* : je peux le faire. *Si je finissais tôt, je passerais te voir* : c'est possible, mais je n'y crois pas trop. *Si j'avais fini tôt, je serais passé te voir* : c'est fini, je n'ai pas fini tôt. Le français utilise le même *si* et change seulement le temps.
{: .fr }

Here are three sentences side by side, to hear the difference in meaning. *Si je finis tôt, je passe te voir*: I can do it. *Si je finissais tôt, je passerais te voir*: it is possible, but I don't count on it. *Si j'avais fini tôt, je serais passé te voir*: it is over, I did not finish early. French uses the same *si* and changes only the tense.
{: .en }

### La phrase mixte

La phrase mixte relie un passé et le présent. La condition est dans le passé (plus-que-parfait), et le résultat est encore vrai aujourd'hui (conditionnel présent) : *Si nous avions réagi l'an dernier, nous aurions déjà un deuxième serveur.* Elle sert souvent à parler d'un choix d'hier qui change la situation d'aujourd'hui.
{: .fr }

The mixed sentence links a past and the present. The condition is in the past (plus-que-parfait), and the result is still true today (conditionnel présent): *Si nous avions réagi l'an dernier, nous aurions déjà un deuxième serveur.* It often talks about a choice made yesterday that changes today's situation.
{: .en }

### Au-delà de *si*

Trois expressions disent la condition sans *si*, et elles sont suivies du conditionnel. *Au cas où* veut dire « in case » : *Prenez un parapluie au cas où il pleuvrait.* *Dans l'hypothèse où* et *dans l'éventualité où* veulent dire « in the event that » et appartiennent à un registre plus soutenu : *Dans l'hypothèse où le budget serait refusé, nous demanderions de l'aide.* *Quand bien même* veut dire « even if » et se trouve surtout à l'écrit : *Quand bien même le budget serait refusé, nous continuerions.* Le conditionnel est ici correct, parce que ce n'est pas *si*.
{: .fr }

Three expressions state the condition without *si*, and they are followed by the conditionnel. *Au cas où* means "in case": *Prenez un parapluie au cas où il pleuvrait.* *Dans l'hypothèse où* and *dans l'éventualité où* mean "in the event that" and belong to a more formal register: *Dans l'hypothèse où le budget serait refusé, nous demanderions de l'aide.* *Quand bien même* means "even if" and is found mostly in writing: *Quand bien même le budget serait refusé, nous continuerions.* The conditionnel is correct here, because this is not *si*.
{: .en }

Trois autres outils servent beaucoup dans les documents de travail : *en cas de* + nom sans article (*en cas de panne*), *au besoin* (« if needed ») et *le cas échéant* (« if applicable »). L'adjectif *éventuel* veut dire « possible » : *une panne éventuelle*. Attention : *éventuellement* veut dire « possibly », pas « eventually ». Pour « finalement » ou « à la fin », écrivez *finalement*. On peut aussi exprimer un souhait impossible avec *si seulement* : *Si seulement nous avions réagi plus tôt!*
{: .fr }

Three other tools are used a lot in work documents: *en cas de* + a noun without an article (*en cas de panne*), *au besoin* ("if needed") and *le cas échéant* ("if applicable"). The adjective *éventuel* means "possible": *une panne éventuelle*. Watch out: *éventuellement* means "possibly", not "eventually". For "in the end", write *finalement*. You can also express an impossible wish with *si seulement*: *Si seulement nous avions réagi plus tôt!*
{: .en }

## Écoutez

Écoutez cette réunion de gestion des risques (vous, entre collègues). Repérez les trois types et la phrase mixte.
{: .fr }

Listen to this risk meeting (vous, between colleagues). Spot the three types and the mixed sentence.
{: .en }

```fr
Lavoie: Si la panne avait duré une heure de plus, qu'est-ce qui se serait passé? | If the outage had lasted one more hour, what would have happened?
Tran: Nous aurions perdu les données de la journée. | We would have lost the day's data.
Inès: Si nous avions une deuxième copie des données, le risque serait plus petit. | If we had a second copy of the data, the risk would be smaller.
Lavoie: Et si nous achetons un deuxième serveur, la question sera réglée? | And if we buy a second server, will the matter be settled?
Tran: Oui. Au cas où la panne reviendrait, nous pourrions repartir en une heure. | Yes. In case the outage came back, we could restart in an hour.
Inès: Dans l'hypothèse où le budget serait refusé, nous demanderions de l'aide. | In the event that the budget were refused, we would ask for help.
Lavoie: Quand bien même le budget serait refusé, je ne laisserais pas ce risque. | Even if the budget were refused, I would not leave this risk.
Tran: Si nous avions réagi l'an dernier, nous aurions déjà un deuxième serveur. | If we had reacted last year, we would already have a second server.
Lavoie: Si seulement nous avions réagi plus tôt! | If only we had reacted sooner!
```

## À vous

1. Donnez le type (1, 2 ou 3) : *Si tu m'appelles demain, je te répondrai.* *S'il pleuvait, nous resterions.* *Si j'avais su, je serais venu.*
2. Complétez : *Si nous ___ (avoir) plus de temps, nous ___ (finir) aujourd'hui.*
3. Complétez : *Si elle ___ (étudier) davantage, elle ___ (réussir) l'examen.* (le passé, trop tard)
4. Complétez : *Si j'avais accepté l'offre, je ___ (habiter) à Ottawa maintenant.*
5. Corrigez les deux phrases du bloc suivant.

```fr
Si j'aurais le temps, je viendrais. {x}
Au cas où il pleuvra, restez ici. {x}
```

<details class="solution" markdown>
<summary>Answer</summary>

1. Type 1, type 2, type 3.
2. *Si nous avions plus de temps, nous finirions aujourd'hui.*
3. *Si elle avait étudié davantage, elle aurait réussi l'examen.*
4. *J'habiterais* (phrase mixte : passé et présent).
5. *Si j'avais le temps, je viendrais.* (jamais de conditionnel après *si*). *Au cas où il pleuvrait, restez ici.* (*au cas où* veut le conditionnel).

</details>

## Dites-le

```fr
Si je finis tôt, je passe te voir. | If I finish early, I'll come by.
Si je finissais tôt, je passerais te voir. | If I finished early, I would come by.
Si j'avais fini tôt, je serais passé te voir. | If I had finished early, I would have come by.
Au cas où la panne reviendrait, nous serions prêts. | In case the outage came back, we would be ready.
Si seulement nous avions réagi plus tôt! | If only we had reacted sooner!
```

## Erreurs fréquentes

Mettre le conditionnel après *si* : « Si j'aurais su ». Écrivez *si j'avais su*. Le conditionnel va dans la proposition de résultat.
{: .fr }

Putting the conditionnel after *si*: "Si j'aurais su". Write *si j'avais su*. The conditionnel goes in the result clause.
{: .en }

Confondre *éventuellement* et « eventually » : *éventuellement* veut dire « possibly ». Pour « à la fin », écrivez *finalement*.
{: .fr }

Confusing *éventuellement* and "eventually": *éventuellement* means "possibly". For "in the end", write *finalement*.
{: .en }

Employer le futur après *au cas où* : « Au cas où il viendra ». Écrivez *au cas où il viendrait*.
{: .fr }

Using the futur after *au cas où*: "Au cas où il viendra". Write *au cas où il viendrait*.
{: .en }

## Termes clés

- **Proposition de condition**: the clause that starts with *si* and gives the condition.
- **Proposition de résultat**: the clause that says what happens or would happen if the condition is met.
- **Phrase mixte**: a *si* sentence with a past condition (plus-que-parfait) and a present result (conditionnel présent).
