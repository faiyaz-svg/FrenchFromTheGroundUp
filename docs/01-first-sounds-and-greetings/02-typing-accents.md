# Typing accents on your keyboard

<span class="tag tag-write">Write</span> <span class="tag tag-a1">A1</span>

After this lesson you can type every French accented letter, the ligature *œ* and the quotation marks « » on your computer and your phone.

Before this: [How French spelling, sounds and rhythm work](01-french-sound-map.md). You need: your Windows computer and, if you like, your phone.

## The idea

The drills in this book check your accents. A word typed without its accent is marked "almost", so you need a way to type them that you can use without thinking. You have four options on Windows, and you only need one. Pick the first one that works for you.

The idea behind most of them is the **dead key**. A dead key is a key that prints nothing when you press it. It waits for the next key and then puts the mark on that letter. This is why a key press can seem to do nothing.

### Option 1: add a Canadian keyboard layout

A **keyboard layout** decides which character each key produces. Windows has two Canadian layouts that suit French: *Canadian French* and *Canadian Multilingual Standard*. The layout files are listed on kbdlayout.info ([Canadian French](https://kbdlayout.info/00001009/), [Canadian Multilingual Standard](https://kbdlayout.info/00011009/)). Choose *Canadian French*, not *Canadian French (Legacy)*, as an independent adviser on [Microsoft Q&A](https://learn.microsoft.com/en-us/answers/a/6083089) also suggests.

1. Open Settings, then Time & language, then Language & region.
2. Add French (Canada) as a language, or open the options of your English language and add a keyboard. The menu names change between Windows builds, so look for "Add a keyboard".
3. Choose Canadian French or Canadian Multilingual Standard.
4. Switch between layouts with the Windows key and the space bar.

In the table, each key is named by what the same physical key prints on a US keyboard. A **dead key** is pressed first, then the letter.

| To type | Canadian French | Canadian Multilingual Standard |
|---|---|---|
| é | the `/` key | the `/` key |
| è | the `'` key (dead grave), then *e* | the `'` key |
| à | the `'` key (dead grave), then *a* | the `\` key |
| ç | the `]` key (dead cedilla), then *c* | the `]` key |
| ù | the `'` key (dead grave), then *u* | the extra key left of *Z*, if your keyboard has it |
| ê | the `[` key (dead circumflex), then *e* | the `[` key (dead circumflex), then *e* |
| ë | Shift and the `]` key (dead tréma), then *e* | Shift and the `[` key (dead tréma), then *e* |
| « » | the extra key left of *Z*, without and with Shift | AltGr and *Z*, AltGr and *X* |
| œ | not on this layout | on an extra level (it sits with the *E* key), so use another option below |

These positions come from the layout files on kbdlayout.info. The extra key left of *Z* exists on keyboards with a short left Shift key, and US-style keyboards (long left Shift) lack it, so « » on Canadian French and *ù* on Multilingual have no key there. Use the dead grave for *ù*, and option 2 or 3 for « ». Open the on-screen keyboard (Windows key, Ctrl and O together) to see any key. Test each one in Notepad before you rely on it.

### Option 2: keep your English keyboard

If you want to keep your usual layout, add the United States-International layout. It acts like a normal US keyboard but adds AltGr shortcuts. The [kbdlayout.info page for it](https://kbdlayout.info/00020409/) lists these four:

| To type | Press |
|---|---|
| é | AltGr and E |
| ç | AltGr and the comma key |
| « | AltGr and the left square bracket |
| » | AltGr and the right square bracket |

The same layout file lists five dead keys: apostrophe, quote, grave, tilde and caret (Shift and 6). So apostrophe then *e* gives *é*, grave then *e* gives *è*, and quote then *e* gives *ë*. Caret then *e* gives *ê*. To print a plain apostrophe, press the key and then the space bar. The layout has no key for *œ*, so use option 3 or 4 for it. Test each one in Notepad before you rely on it.

### Option 3: the symbol panel

Press the Windows key and the period key together. The emoji panel opens. Choose the symbols section (the Ω icon) and look in the Latin group for letters with accents. This is slow, so use it only for a rare character.

### Option 4: number codes as a last resort

Hold Alt, type the number on the numeric keypad, and release Alt. You need a keypad with Num Lock on, so it fails on many laptops. These are the Windows codes (they come from the Windows-1252 character set); the leading zero is part of the code.

| Letter | Code | Letter | Code |
|---|---|---|---|
| é | Alt 0233 | ë | Alt 0235 |
| è | Alt 0232 | ï | Alt 0239 |
| ê | Alt 0234 | ô | Alt 0244 |
| à | Alt 0224 | û | Alt 0251 |
| ç | Alt 0231 | ù | Alt 0249 |
| œ | Alt 0156 | « » | Alt 0171, Alt 0187 |

### On a phone

Press and hold a letter and a small menu appears. Hold *e* for *é*, *è*, *ê* and *ë*. Hold *a* for *à*, *c* for *ç*, *o* for *ô* and *œ*, *u* for *ù* and *û*, and *i* for *î* and *ï*. Adding the French keyboard in your phone settings also gives you « » and autocorrect in French.

## Try it

Pick your method and type the words in the block below. Compare each one letter by letter with the page.

```fr
le café | coffee
L'été | summer
la fête | party
L'école | school
Noël | Christmas
sûr | sure
L'œuf | egg
le cœur | heart
« Bonjour » | "Hello"
```

1. Type the nine items above. How many have the right accents on the first try?
2. Type the line *Où est l'hôtel?* (Where is the hotel?) with every accent.
3. Which of *ecole*, *ete*, *fete* and *coeur* needs a ligature and not an accent?
4. Type *garçon*, *père* and *français* with all accents.

<details class="solution" markdown>
<summary>Answer</summary>

1. Aim for all nine. If one fails, repeat that method on the single letter and then on the word.
2. *Où est l'hôtel?* has *ù* and *ô*.
3. *Coeur*. It is written *cœur*, with the single letter *œ*.
4. *Garçon*, *père*, *français*. The marks are *ç*, *è* and *ç*.

</details>

## Say it

Say each word as you type it. The sound and the spelling go together.

```fr
Le café et le thé. | The coffee and the tea.
Où est l'école? | Where is the school?
L'été, c'est la fête. | Summer is party time.
```

## Common mistakes

Pressing a dead key and the letter at the same moment. A dead key waits, so press it first, release it, and then press the letter.

Choosing the wrong accent. *É* says /e/ and *è* says /ɛ/. Say the word first, then choose.

Typing *oe* for *œ*. The ligature is a single letter, and *coeur* is a spelling error.

## Key terms

- **Dead key**: a key that prints nothing until you press the next letter, which then gets the mark.
- **Keyboard layout**: the plan that says which character each key makes.
- **Ligature**: two letters written as one, such as *œ*.
