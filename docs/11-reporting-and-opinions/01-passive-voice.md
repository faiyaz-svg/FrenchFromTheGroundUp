## L'idée

Dans une phrase active, le sujet fait l'action : *Le conseil adopte la loi.* Dans une phrase passive, le sujet reçoit l'action : *La loi est adoptée par le conseil.* Le passif (*la voix passive*) se forme avec *être* et le participe passé.
{: .fr }

In an active sentence, the subject does the action: *Le conseil adopte la loi.* In a passive sentence, the subject receives the action: *La loi est adoptée par le conseil.* **The passive** (*la voix passive*) is built with *être* and the past participle.
{: .en }

### Former le passif

Il y a trois étapes. Un : mettez *être* au temps voulu. Deux : ajoutez le participe passé, et accordez-le avec le sujet. Trois : si vous voulez nommer celui qui agit, ajoutez *par* (c'est le complément d'agent).
{: .fr }

There are three steps. One: put *être* in the tense you need. Two: add the past participle and make it agree with the subject. Three: if you want to name who acts, add *par* (this is the agent, *le complément d'agent*).
{: .en }

| Temps | Phrase | Sens |
|---|---|---|
| présent | *La loi est adoptée.* | The law is passed. |
| imparfait | *La loi était adoptée.* | The law was (being) passed. |
| passé composé | *La loi a été adoptée.* | The law was passed. |
| plus-que-parfait | *La loi avait été adoptée.* | The law had been passed. |
| futur simple | *La loi sera adoptée.* | The law will be passed. |
| conditionnel | *La loi serait adoptée.* | The law would be passed. |

Le temps est dans le verbe *être*. Le participe passé s'accorde toujours avec le sujet. Au passé composé, *été* est invariable, mais le participe qui suit s'accorde : *La loi a été adoptée. Les lois ont été adoptées. Le projet a été adopté.*
{: .fr }

The tense is carried by *être*. The past participle always agrees with the subject. In the passé composé, *été* never changes, but the participle after it agrees: *La loi a été adoptée. Les lois ont été adoptées. Le projet a été adopté.*
{: .en }

Seuls les verbes avec un complément d'objet direct (celui qui répond à *quoi?* ou *qui?*) ont un passif : *adopter une loi*, donc *une loi est adoptée*. On ne peut pas dire *Marie a été téléphoné*, parce que *téléphoner à quelqu'un* n'a pas d'objet direct.
{: .fr }

Only verbs with a direct object (the one that answers *quoi?* or *qui?*) have a passive: *adopter une loi*, so *une loi est adoptée*. You cannot say *Marie a été téléphoné*, because *téléphoner à quelqu'un* has no direct object.
{: .en }

### Par ou de

*Par* est le choix habituel : *Le projet est financé par la Ville.* Avec un sentiment ou un état, on voit aussi *de* : *Elle est respectée de tous.* *La route est couverte de neige.* Quand l'agent est inconnu ou sans importance, on le laisse : *La route a été fermée.*
{: .fr }

*Par* is the usual choice: *Le projet est financé par la Ville.* With a feeling or a state you also see *de*: *Elle est respectée de tous.* *La route est couverte de neige.* When the agent is unknown or unimportant, leave it out: *La route a été fermée.*
{: .en }

### Éviter le passif

À l'oral, les Français et les Québécois préfèrent *on* : *On a adopté la loi hier.* *On m'a dit que le bureau était fermé.* En anglais, on dit « I was told ». En français, *Je suis dit* n'existe pas, parce que *dire* se construit avec *à quelqu'un*. Dites *On m'a dit*.
{: .fr }

In speech, French speakers prefer *on*: *On a adopté la loi hier.* *On m'a dit que le bureau était fermé.* English says "I was told". French has no *Je suis dit*, because *dire* takes *à quelqu'un*. Say *On m'a dit*.
{: .en }

Il existe une troisième forme, **le passif pronominal** : le verbe pronominal (*se vendre*, *se dire*, *se parler*) sans agent, pour une chose ou une règle générale. *Ce produit se vend en pharmacie.* *Ça ne se dit pas.* *Le français se parle au Québec.* Comparez : *Ce produit est vendu en pharmacie* parle d'un cas précis.
{: .fr }

A third form is **the pronominal passive** (*le passif pronominal*): a reflexive verb (*se vendre*, *se dire*, *se parler*) with no agent, for a thing or a general rule. *Ce produit se vend en pharmacie.* *Ça ne se dit pas.* *Le français se parle au Québec.* Compare: *Ce produit est vendu en pharmacie* talks about one specific case.
{: .en }

### Les titres de journal

Dans un titre, on enlève souvent *être* : *Un règlement adopté à Québec.* *Un pont fermé pour deux semaines.* Le participe passé suffit, et il s'accorde toujours : *Des rues fermées.* Vous verrez ce style dans [Les nouvelles](06-news-vocabulary.md).
{: .fr }

In headlines, *être* is often dropped: *Un règlement adopté à Québec.* *Un pont fermé pour deux semaines.* The participle alone is enough, and it still agrees: *Des rues fermées.* You will see this style in [News vocabulary](06-news-vocabulary.md).
{: .en }

## À vous

1. Mettez à la voix passive : *Le maire annonce la décision.* *Le conseil a voté la loi.* *On construira un pont.* *Le gouvernement a interdit les sacs.*
2. Remplacez le passif par *on* : *Le contrat a été signé hier.* *Les règles seront publiées demain.*
3. Accordez le participe : *La loi a été (adopter).* *Les enfants ont été (inviter).* *Les rues seront (fermer).*
4. Choisissez : *Ce produit ___ (se vendre / être vendu) partout.* *Le français ___ (se parler / être parlé) au Québec.*
5. Écrivez un titre de journal passif sur un pont, un règlement ou un nouveau parc.

<details class="solution" markdown>
<summary>Answer</summary>

1. *La décision est annoncée par le maire.* *La loi a été votée par le conseil.* *Un pont sera construit.* *Les sacs ont été interdits par le gouvernement.*
2. *On a signé le contrat hier.* *On publiera les règles demain.*
3. *adoptée*, *invités*, *fermées*.
4. *se vend* (règle générale). *se parle* (règle générale).
5. Exemple : *Un nouveau parc ouvert à Gatineau.* *Un pont fermé pour la fin de semaine.*

</details>

## Dites-le

```fr
La loi a été adoptée hier. | The law was passed yesterday.
Les règles seront publiées demain. | The rules will be published tomorrow.
Le pont a été fermé par la Ville. | The bridge was closed by the City.
On m'a dit que le bureau était fermé. | I was told the office was closed.
Ça ne se dit pas. | That isn't said.
```

## Erreurs fréquentes

Oublier l'accord. Le participe s'accorde avec le sujet : *adoptées*.

```fr
Les lois sont adopté. {x} | Wrong: the participle must agree (adoptées).
```

Utiliser *avoir*. Pour le passif, on a besoin de *être* : *La loi est adoptée*, *La loi a été adoptée*.

```fr
La loi a adoptée. {x} | Wrong: the passive needs être.
```

Traduire « I was told » mot à mot : *Je suis dit* n'existe pas. Dites *On m'a dit*.

## Termes clés

- **Passif (voix passive)**: a sentence where the subject receives the action; it uses *être* and a past participle that agrees with the subject.
- **Complément d'agent**: the person or thing that does the action in a passive sentence, introduced by *par* (sometimes *de*).
- **Passif pronominal**: a reflexive verb used with no agent to say what is usually done (*ça se vend*).
